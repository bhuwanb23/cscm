## Known Limitations & Workarounds

### Service Spin-Down (Render Free Tier)
- **Limitation**: Services sleep after 15 minutes inactivity
- **Current Status**: Services may cold-start on first request
- **Mitigation**: GitHub Actions keep-alive workflow configured
- **Note**: Keep-alive workflow not yet tested (requires manual enablement)

### PostgreSQL 30-Day Expiration
- **Limitation**: Free PostgreSQL expires after 30 days
- **Current Status**: Using existing PostgreSQL (not Render's free tier)
- **Mitigation**: No expiration limitation with existing database
- **Note**: Database URL configured in Render dashboard for security

### GitHub Actions Usage
- **Limitation**: Keep-alive workflow may exceed 2,000 minute free limit
- **Current Status**: Workflow not yet enabled
- **Mitigation**: Consider switching to cron-job.org (free external service)
- **Note**: Documented in deployment guide

### Compute Hours Limit
- **Limitation**: 750 hours/month shared across services
- **Current Status**: Within limits (services cold-start when not in use)
- **Mitigation**: Keep-alive only during working hours if enabled
- **Note**: Currently under limit with cold-start behavior

## Issues Resolved During Validation

### 1. Gateway Metrics Error
- **Issue**: `activeConnections.hashMap.get is not a function`
- **Cause**: Prom-client internal API change in newer versions
- **Resolution**: Simplified metrics middleware to avoid internal API access
- **Status**: ✅ Fixed and deployed

### 2. Husky Build Error
- **Issue**: `husky: not found` during production build
- **Cause**: Husky is a dev dependency, not installed with `npm ci --only=production`
- **Resolution**: Removed `prepare` script from package.json
- **Status**: ✅ Fixed and deployed

### 3. Package-Lock.json Sync
- **Issue**: `npm ci` failed due to missing `pg` dependency in lock file
- **Cause**: Added `pg` dependency without updating lock file
- **Resolution**: Ran `npm install` to update lock file
- **Status**: ✅ Fixed and deployed
